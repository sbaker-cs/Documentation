== Claude

[cols="1,2,2,2,2", options="header"]
|===
| | CLAUDE.md | Skills | Subagents | Hooks

| *Scope*
| All conversations (project-wide)
| Current conversation
| Separate execution context
| Event-driven, per tool call

| *Activation*
| Always active
| Request-driven (based on what you ask)
| Explicitly delegated
| Fires on events (e.g. file save, tool call)

| *Context*
| Sets permanent standards and constraints
| Adds knowledge/instructions to current conversation
| Isolated from main conversation; returns results
| Runs side-effect commands outside conversation

| *Use for*
| Project-wide standards; coding style; permanent constraints
| Task-specific expertise; detailed procedures; knowledge only sometimes relevant
| Delegating tasks needing different tools or isolation
| Linting on save; validation before tool calls; automated side effects

| *Example*
| "Never modify the database schema"
| Activate a "code-review" skill when reviewing a PR
| Run a build validator in a separate worktree
| Run a linter every time Claude writes a file
|===

=== Skills

.Pros and Cons of different Claude features
|===
| | Feature | Skills
| Claude.md 
a| 
  * Project-wide standards that always apply
  * Constraints like "never modify the database schema"
  * Framework preferences and coding style 
a| 
  * Task-specific expertise
  * Knowledge that's only relevant sometimes
  * Detailed procedures that would clutter every conversation

| SubAgents 
a| 
  * You want to delegate a task to a separate execution context
  * You need different tool access than the main conversation
  * You want isolation between delegated work and your main context
a|
  * You want to enhance Claude's knowledge for the current task
  * The expertise applies throughout a conversation

| Hooks 
a| 
  * Operations that should run on every file save
  * Validation before specific tool calls
  * Automated side effects of Claude's actions
a|
  * Knowledge that informs how Claude handles requests
  * Guidelines that affect Claude's reasoning
|===

==== Claude Code SDK

[source, bash]
.CLI
----
claude -p "Look for duplicate queries"
----

[source, ts]
.Typescript
----
import { query, SDKMessage } from "@anthropic-ai/claude-code"

const prompt = "Look for duplicate queries"

for await (const message of query({
    prompt,
    options: {
        allowedTools: ["Edit"]
    }
})) {
    console.log(message)
}
----

[source, python]
.Python
----
import anyio
from claude_code_sdk import ClaudeSDKClient, ClaudeAgentOptions

options = ClaudeAgentOptions(allowed_tools=["Edit"])

async def main():
    prompt = "Look for duplciate queries"
    async with ClaudeSDKClient(options=options) as client:
        await client.query(prompt=prompt)
        async for msg in client.receive_response():
            print(msg)
----
